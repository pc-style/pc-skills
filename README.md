# PC Skills

**Audience: reusable developer-agent workflows.** This repository is for generally
applicable software-engineering skills. Personal operating procedures belong in the
private `skills` repository; skills that require the OpenClaw runtime belong in
[`openclaw-skills`](https://github.com/pc-style/openclaw-skills).

## Provenance and licensing

Licensing is component-specific. This repository does not currently declare a
repository-wide license.

`address-gh-comments` is adapted from OpenAI's
[`gh-address-comments`](https://github.com/openai/skills/tree/main/skills/.curated/gh-address-comments)
skill. Its upstream Apache-2.0 license is retained at
[`address-gh-comments/LICENSE.txt`](address-gh-comments/LICENSE.txt). No license is
asserted here for components that do not contain their own license notice.
